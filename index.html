Bienvenue dans Meuk

Tes dépenses restent sur ce téléphone, chiffrées. Pour les protéger, Meuk va :

  1. créer une passkey protégée par Face ID ;
  2. te donner une phrase de secours de 12 mots, à noter sur papier.

Ouvre Meuk depuis son icône sur l'écran d'accueil, pas depuis Safari : les deux n'ont pas les mêmes données.

Activer le chiffrement

Passkey créée. Une dernière confirmation Face ID permet de fabriquer ta clé de chiffrement.

Ta phrase de secours

Note ces 12 mots sur papier, dans l'ordre, avec leur numéro. Ils permettent de tout récupérer si tu perds ta passkey.

Pas de photo, pas de capture d'écran, pas de Notes. Personne d'autre ne doit les voir. Ils ne seront plus jamais affichés.

    Vérification

    Retape les mots demandés, à partir de ton papier. Les accents sont facultatifs.

    Meuk est verrouillée

    Phrase de secours

    Tape tes 12 mots dans l'ordre, séparés par des espaces. Les accents sont facultatifs.

    Nouvelle passkey

    Phrase correcte : tes données sont déverrouillées. Crée une nouvelle passkey pour retrouver Face ID. Elle remplacera l'ancienne.
